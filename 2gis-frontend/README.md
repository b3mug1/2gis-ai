
City Guide AI is a Vite + React + TypeScript frontend.

## Getting Started

Install dependencies and start the development server:

```bash
npm run dev
# or
yarn dev
Open [http://localhost:7000](http://localhost:7000) with your browser to see the result.

The dev server uses the default Vite port `5173`.

Set `VITE_API_URL` and `VITE_TWOGIS_API_KEY` in `.env.local` when running against a non-default backend.

## Production

```bash
npm run build
npm run preview
```
